# 救砖

## 刷了 paduex5_1.0～1.5 → 插上无声音

USB 中断向量被覆盖（见 `patches/paduex5_1.0-Vector-Brick.md`）。APP 起不来，**OTA 无法再进**。

只能 ISP / SWD：

1. 固件：`paduex5_1.7.bin`（或 paduex5_1.6 / 官方 V2.13）  
2. 地址：`0x08004000`，写满 37072 字节  
3. 复位

## 新板升级建议（两步）

1. 先用 PADUEX5 OTA 刷 **官方 V2.13** —— 验证升级工具与 Bootloader 路径本身无问题  
2. 再 OTA 刷 **paduex5_1.7.bin**

| 固件 | 结论 |
|------|------|
| **paduex5_1.7** | 推荐（防粘键 + 改键） |
| paduex5_1.6 | 保守版（仅防粘键） |
| 官方 V2.13 | 安全基线 |
| paduex5_1.0～1.5 | **禁止** |
