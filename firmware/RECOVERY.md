# 板子刷 grok1.1 后 USB「无法识别 / 闪一下消失」说明

## 原因（高概率）

`grok1.1.bin` 比原厂 / `grok1.0` **多出约 228 字节**（末尾 code cave）。

上电初始化里有一条固定跳转：

- `0x080064B0` → `Mapping_Load` @ `0x0800D0E8`（就在多出来的那段里）

若雅特力 **ISP / IPS 工具**没有把整文件写完整（或只按旧体积写、地址不对），`0x0800D0E8` 一带仍是擦除态 `0xFF`：

1. Bootloader 正常启动并跳到 APP  
2. APP 一跑到加载映射就 **HardFault**  
3. USB 刚枚举就掉线 → 电脑显示「无法识别的 USB 设备」然后消失  

这和「键盘改键逻辑写坏了」不是一回事，而是 **镜像被截断 / 刷写地址不对** 导致启动必崩。

此前上位机 OTA 用控制传输失败时，一般还没开始写 Flash；真正写坏 APP 区的，多半是随后用 ISP 刷 `grok1.1.bin` 这一步。

## 救砖（推荐）

用原厂 **ISP Programmer**（串口/USB ISP，按板子进 ISP 方式：BOOT0 或厂家说明）：

1. 固件选官方 **`5KEY_2P_V2.13.bin`**，或本仓库更稳妥的 **`firmware/grok1.0.bin`**（无末尾 cave）  
2. **下载地址必须是 `0x08004000`**（APP 区，不要 `0x08000000`，否则会盖掉 Bootloader）  
3. 确认工具写入的长度 ≥ 文件完整大小（grok1.0 = 37072 字节）  
4. 写完复位，应能重新被 PADUEX5 识别  

若 ISP 仍进不去：需要 SWD（如 AT-Link / J-Link）擦除并重写 APP，或找厂家救砖。

## 关于 grok1.1

| 方式 | 建议 |
|------|------|
| 本仓库 PADUEX5 OTA（v1.0.0.47+，中断 IAP，整包写入） | 可写完整 cave，按设计可用 |
| 原厂 ISP / 只认旧体积的工具 | **不要刷 grok1.1**，用 grok1.0 或官方 V2.13 |

后续会提供**不超出原厂体积**的改键固件；在此之前请用 `grok1.0` / 官方包救砖与日常使用。
