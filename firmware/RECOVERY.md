# 救砖

## 刷了 grok1.0～1.5 → 插上无声音

USB 中断向量被覆盖（见 `patches/grok1.0-Vector-Brick.md`）。APP 起不来，**OTA 无法再进**。

只能 ISP / SWD：

1. 固件：`grok1.6.bin` 或官方 `5KEY_2P_V2.13.bin`  
2. 地址：`0x08004000`，写满 37072 字节  
3. 复位

## 新板升级建议（两步）

1. 先用 PADUEX5 OTA 刷 **官方 V2.13** —— 验证升级工具与 Bootloader 路径本身无问题  
2. 再 OTA 刷 **grok1.6.bin**

| 固件 | 结论 |
|------|------|
| **grok1.6** | 推荐 |
| 官方 V2.13 | 安全基线 |
| grok1.0～1.5 | **禁止** |
