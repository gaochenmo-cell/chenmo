# 变砖救回说明

## A. 刷了 grok1.3 → 插上无声音 / 无设备

**原因**：1.3 的 `SendPacket` 压栈少了 `r8`，破坏 8 字节对齐，USB 发送路径 HardFault。  
**不是** ISP 截断（1.3 与原厂同长）。详见 `patches/grok1.3-Brick.md`。

### 救法

1. **ISP Programmer**：固件选 **`grok1.4.bin`**（或 `grok1.2.bin` / 官方 V2.13）  
2. 下载地址 **`0x08004000`**，写满 **37072** 字节  
3. 复位后应重新枚举  

若仍在 Bootloader（OTA 设备 VID `0x0E8F` PID `0x8901`）：用 PADUEX5 固件升级刷 **grok1.4.bin**。

## B. 刷了 grok1.1 → USB 闪一下消失

**原因**：1.1 比原厂长约 228 字节；ISP 按旧长度写会截断 cave → `Mapping_Load` HardFault。

改刷 **grok1.4 / 1.2 / 1.0**（同体积），地址 `0x08004000`。

## 固件怎么选

| 固件 | 体积 | 改键 | 粘键超时 | 栈对齐 | ISP/OTA |
|------|------|------|----------|--------|---------|
| **grok1.4.bin** | 37072 | 有 | 有 | 正确 | **推荐** |
| grok1.2.bin | 37072 | 有 | 无 | 正确 | 可用 |
| grok1.0.bin | 37072 | 无 | 无 | 正确 | 可用 |
| ~~grok1.3.bin~~ | 37072 | 有 | 有 | **错误** | **禁止** |
| ~~grok1.1.bin~~ | +228 | 有 | 无 | — | **禁止 ISP** |
| 官方 V2.13 | 37072 | 无 | 无 | 正确 | 可用 |
