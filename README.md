# PADUEX5

## 下载

- [`dist/PADUEX5/`](./dist/PADUEX5/) → `PADUEX5.exe`
- [`dist/PADUEX5-win-release.zip`](./dist/PADUEX5-win-release.zip)

## 固件

请刷 **`firmware/grok1.5.bin`**（改键 + 修复 1.2 boot 变砖）。

**不要**刷 grok1.2 / 1.3 / 1.4（OTA 成功后也可能无 USB）。救砖见 [`firmware/RECOVERY.md`](./firmware/RECOVERY.md)。

## 本地编译

Visual Studio 打开 `ConfigApp/HIDDeviceProject.sln`（.NET 4.0）。
